# monju-advisor

Claude Code の入力欄のすぐ上に monju ボタンを置く mod です(三人寄れば文殊の知恵)。
ボタンを押すと、Claude(Opus 5.5)が人の立場になって第三者の目でやり取りを読み、一番強い反対意見を軸にした「人がそのまま送れる返事」の下書きを入力欄に足します。
人はそれを参考に直して送ります。
押さなければ何も出さず、モデルも呼びません。

## 何をするか

押すと、会話と入力欄の打ちかけの文を材料に、Opus 5.5 を1回呼びます。返事は次の形で入力欄の後ろに足します。

```
<人がそのまま Claude に送れる返事>
(別視点:<反対の中身と根拠>)
```

例(Claude が「キャッシュは Redis を入れる案を推奨します。どうしますか?」と聞いた場面。分かりやすくするために作った例です):

```
Redis を入れる前に、今の遅さがどのクエリから来ているかを先に測ってもらえますか。原因が分かってから決めたいです。

(別視点:遅いのは一覧画面だけだと最初に書いています。原因が N+1 のクエリなら、Redis を入れても速くならず、運用するものが1つ増えるだけです。)
```

- 軸は反対意見です。一番強い反対を1つ探します。相手は2つです
  1. Claude の推奨や案:人の目的・好みから見て、別の案の方が合わないか
  2. 人自身の方針や前提:人の目的と食い違っていないか、決める前に人が確かめるべき事実は無いか
- 反対には根拠(会話のどこから・人にとって何が起きるか)を付けるよう頼んでいます。何がどうなのか言わない反対は書かせません
- すでに決めたことに反対するのは、決めたときの前提が崩れた根拠が会話にあるときだけです
- 根拠のある反対が無ければ、無理に作らず、推奨どおりでよい理由を書いた下書きにします
- 全体で 200 字以内にするよう頼んでいます。コードでは切りません
- 入力欄に打ちかけの文があれば、それも反対の相手にし、下書きはその後ろに改行してから足します。打った文は消しません(待つ間に打ち足した文も残ります)
- 参考にするための下書きで、正しさは確かめていません

基準の文は [monju-advisor/hooks/judge.ts](monju-advisor/hooks/judge.ts) の `RULES` にあります。

## 見る所

- 見るのは、いま人の前にある「人が決めること」(Claude が聞いている選択・推奨・方針)と「人が確かめること」(人の画面・好み・目的など、人にしか分からない事実)だけです
- Claude の作業の進め方(ファイルを読んだか・検証の手順 など)には口を出しません。反対の根拠にも使いません

## 使い方

1. 入力欄のすぐ上の帯にある `monju` ボタンを押す
2. 「monju: 考えています」と出て、約 20 秒で入力欄の後ろに下書きが入る
3. 下書きを直して送る

- 作っている間にもう一度押しても無視します
- 作れなかったとき(時間切れ・API エラー・空の返事)は「monju: 下書きを作れませんでした(<理由>)」と出し、入力欄は触りません
- 回答の途中で押したときも、押した時点の会話で作ります
- アンケートの表示中は、ボタンを出しません
- ボタンを消したいときは、mod ごと無効にします(on / off のコマンドはありません)

## 渡す材料

| 渡すもの | 量 |
|---|---|
| 人の発言(直近3往復より前) | 初めから全部。1つにつき先頭 2000 字 |
| 直近3往復の人の発言と Claude の回答 | 全文 |
| 直近3往復の道具(ツール) | 名前と入力の先頭 150 字、結果の先頭 200 字 |
| 入力欄の打ちかけの文 | 全文(あるときだけ) |

- 人の発言のうち、仕組みが足すもの(`<system-reminder>` などで始まるもの)は捨てます
- 会話に出てこなかったファイルは見ません

## モデル・時間・費用

- モデルは `claude-opus-5-5`、考える深さ(effort)は low です。返事は最大 4000 トークン、待つのは 60 秒までです
- 呼ぶのは押したときの1回だけです
- 作者の試しでは1回 17〜21 秒、約 $0.02〜0.03 でした(`claude -p` で3回試した値。この mod からの呼び出しで同じになるかは確かめていません)

## 分かっている限界

- 下書きの質は、作者の3つの会話で1回ずつ試しただけです。3件とも、人が決めることへの、根拠のある反対になりました。外れは使いながら集めて直します
- 会話に出てこなかったファイル(決定の記録など)は見ないので、会話で読んでいない決定に反対することがあります
- `<system-reminder>` などが人の発言に混ざるかは、この mod の呼び出しでは確かめていません
- 見え方を確かめたのは VS Code だけです。端末での見え方は試していません

## 入れ方

このリポジトリをマーケットプレイスとして登録して入れます。

```
claude plugin marketplace add AndoYuto87/monju-advisor
claude plugin install monju-advisor@monju-advisor
```

## テスト

リポジトリの直下で:

```
claude plugin validate ./monju-advisor
claude plugin test ./monju-advisor
```
